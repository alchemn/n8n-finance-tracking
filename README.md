
# FinanceTracker Pro

FinanceTracker Pro adalah aplikasi web yang membantu Anda mengelola keuangan pribadi dengan mudah. Dengan tampilan yang sederhana dan fitur-fitur lengkap, aplikasi ini cocok untuk memantau pemasukan, pengeluaran, dan pengelolaan anggaran Anda. Tersedia juga panel admin untuk memantau kinerja platform secara keseluruhan.

## ✨ **Fitur Utama**

### Untuk Pengguna
- ✅ **Pantau Keuangan**: Lihat semua transaksi dan saldo Anda dalam satu tempat.
- 📊 **Analisis Pengeluaran**: Lihat rincian pengeluaran harian, mingguan, dan bulanan *(Fitur Pro)*.
- 🏷️ **Kelola Kategori**: Atur pengeluaran Anda berdasarkan kategori untuk lebih mudah memantau.
- 💳 **Paket Berlangganan**: Mulai dengan paket Gratis atau upgrade ke Pro untuk akses lebih banyak fitur.

### Untuk Admin
- 📈 **Pantau Pengguna**: Lihat jumlah pengguna dan data distribusinya.
- 💰 **Lihat Laporan Pendapatan**: Pantau pendapatan bulanan dan tahunan.
- ⚙️ **Kelola Platform**: Periksa tren pengeluaran pengguna dan data platform lainnya.

## 🛠️ **Teknologi yang Digunakan**
- **Framework**: [Next.js](https://nextjs.org/)
- **Bahasa**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [Shadcn/UI](https://ui.shadcn.com/)
- **Database**: [MongoDB](https://www.mongodb.com/) dengan [Mongoose](https://mongoosejs.com/)
- **Autentikasi**: [Next-Auth](https://next-auth.js.org/)
- **Validasi Form**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)
- **Visualisasi Data**: [Recharts](https://recharts.org/)
